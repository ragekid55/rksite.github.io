Before starting

I’m not sure if i’ll continue working on this game. At first, i thought it would be fun and interesting to create something like this, but now idk. Maybe i’ll do something different.

About the game

Greg’s School is a small game where the main char finds himself in a strange school and has to kill children. The game will feature pixel art since that’s the easiest option for me right now (wanna learn 3D btw). You as a player will need to explore the school, discover its secrets, and fight bosses— Math, for example.

GAMEPLAY

It’s a top-down shooter. The main character is armed with a shotgun with infinite ammo. He’s not immortal and can die if attacked by certain school inhabitants.
